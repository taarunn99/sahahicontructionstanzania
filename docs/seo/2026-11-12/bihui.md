  were left to Mapei and the solution pillars. Tool queries only.

  cutter, manual tile cutter. Every other title is `<Tool> - BIHUI <class> |
  Sahihi` and the description carries Tanzania.

  35 rows use `titleOverride` (a source typo, a name over budget, or a
  query-led reorder); the rest compose from the catalogue name and `typeWords`.

  tool name and query words first, then codes, sizes, materials or capacities,
  then the source line and a call to action ("see it in 3D" on the 75 pages with
  a model, "ask for a quotation" on the six without). No two queries or titles
  repeat; no more than five rows share the same last 60 characters.
- Stock is `order` on every row: the owner's word is that any tool is arranged
  4 days after confirmation. No row says "in stock".

  two hydro sponges (printed size contradicts the code), the two suction cups

  cutter and trim puller (one code printed for both tools).

  under "Name corrections for titles, 2026-11-12". The JSON is untouched.
