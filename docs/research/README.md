# Research index - 2026-11-05

Fourteen reports written in parallel on 2026-11-05. Each opens with its
own method-and-limits paragraph: read it before quoting a finding.

**Limits that apply to all of them**

- The web search tool is US-located (two reports also used Brave with
  country=tz and Yahoo). **No Google Tanzania rankings were measured.**
- The fleet shared a 200-search cap and exhausted it. Keyword reports
  checked 13 to 25 queries live, not the 30+ they were asked for; the
  rest are marked "inferred" or "not checked".
- No search-volume data (Ahrefs is not connected) and no People Also Ask
  data (the tool does not return it).
- mapei.com, jiji.co.tz, LinkedIn and a few retailer sites block
  automated fetching. Mapei facts come from Mapei's PDF data sheets.
- Every claim carries its source URL in the report. "Not verified" means
  exactly that.
