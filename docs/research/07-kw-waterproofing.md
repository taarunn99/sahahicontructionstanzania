**Three biases in the SERP data.**
1. The search tool is a US-located index, not google.co.tz from a Tanzanian IP. A Dar es Salaam user will see a local pack, more .co.tz results and possibly Swahili results that I could not see. Treat every grade as "organic competition as seen from outside Tanzania".
2. Result order is the order the tool returned, used as an approximation of rank. It is not a verified position.
3. Grades are my judgment from SERP composition (who ranks, what page type, how old, how relevant). They are not difficulty scores from a tool.

**Baseline that affects every grade.** On 2026-11-05 https://sahihicc.com returned a Namecheap parking page ("Your website is ready to go!"), with no content and no indexed pages. The new site starts from zero authority, so EASY below means "weak SERP", not "will rank in weeks".

**Recommended follow-up (about 20 searches, ideally from a Tanzanian IP or a rank tool set to Tanzania):** the unchecked queries marked `no` in section 2, plus PAA and local-pack capture for the 10 head and application terms.
