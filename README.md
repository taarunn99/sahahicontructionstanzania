# sahihicc.com

Catalogue site for **Sahihi Construction Chemicals Limited**, Dar es
Salaam: authorized distributor of Mapei, Oriental Yuhong and X-Calibur.
Built on the gcbuae.com system (Next.js 16, React 19, Tailwind v4, GSAP,
Motion, Lenis).

## Run it

```bash
npm install
npm run dev              # http://localhost:3000
npm run check            # typecheck + lint + build + audits
scripts/lighthouse.sh    # mobile Lighthouse on the production build
```

Keep the working copy in `~/dev/sahihicc`. Never an iCloud-synced folder.
